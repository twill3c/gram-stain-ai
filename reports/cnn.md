## 学習系の陽性対照(G-09)

ラベルを無作為に置き換えて同じ手続きを回すと、macro F1 は **0.4356** [0.4074, 0.4625] だった(多数派クラス 0.4171)。

信号を消せば成績も消える。**損失の比では対照にならない**(HC-163)ので、
最終的な macro F1 で見ている。ここで成績が残るなら、
それは入力の信号ではなく手続きの漏れが出している数である。

## 判定

合否条件は [SPEC.md](../SPEC.md) の 3.4 節に**測る前に**書いた。
当てはめる仕事は機械にさせている(検査 T-235)。

- 条件 1(三つの物差しすべてで色の規則を信頼区間の重なりなく上回る): **不成立**
- 条件 2(色の規則が落ちる分類群で明確に上回る): **成立**

成立した条件については、下の内訳でどこが効いたかを見る。

### 条件 2 の内訳

対象の選び方: 物差し B で色の規則の誤り率が 10% 以上だった分類群

| 分類群 | 色相の誤り率 | CNN の誤り率 |
|---|---|---|
| Listeria monocytogenes | 44% | 33% |
| Porphyromonas gingivalis | 37% | 35% |
| Staphylococcus epidermidis | 14% | 2% |

対象 3 分類群のうち CNN が改善したのは 3、
誤り総数は色相 60 対 CNN 45。

## 物差しごとの差が意味すること

- CNN: A 0.9731 → B 0.9276 → C 0.6942
- 色相: A 0.9714 → B 0.9524 → C 0.9601

色の規則は物差しを変えてもほとんど動かない。色は種の同一性に依らないからである。
**CNN のほうが大きく落ちるなら、その落ちた分が「種の見覚え」だった**ということになる。
落ちないなら、CNN も種に依らない手がかりを見ていることになる。

## 出荷するモデル

物差し A の 70/15/15 で学習した。train で作り、val で確認し、
**test には最後に一度だけ**当てた(test_evaluations = 1・G-08)。

| 項目 | 値 |
|---|---|
| エポック | 3 |
| val macro F1 | 0.9829 |
| test macro F1 | 1.0(286 枚) |
| test 正解率 | 1.0 |

### この数だけを出してはならない

**この test macro F1 1.0 は、本プロジェクトが警告している当のものである。**
正しい手順で出した数ではある —— train で学習し、val で確認し、test には一度だけ当てた。
それでもこの数は、**同じ分類群のスライドを見分ける課題**の成績でしかない。

同じ骨格・同じ手続きで、科をまるごと抜けば 0.6942 まで落ちる。
落差は物差しの取り方だけから来ている。

だからこの数は、**単独では出さない**。三つの物差しの表と必ず並べる。
