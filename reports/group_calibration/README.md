# group の閾値をどう決めたか(loop_002・2026-09-08)

SPEC §6.1 は「閾値は**まとめすぎ / まとめ足りない**の両方向を目視で確かめてから決める」と定める。
片方向だけ見ると、閾値は必ず自分の都合のいい方へ寄る。本書はその記録である。

## 決めたもの

| 規則 | 値 | 根拠 |
|---|---|---|
| 知覚ハッシュ(dhash 256bit)の近傍 | ハミング距離 ≤ **45** | 距離の分布に 36〜54 の谷がある。谷の中に置いた |
| スライドの代理(同一 分類群+キャンバス寸法) | セルの枚数 ≤ **12** をまとめる | 1225px を除くセルの最大が 12 枚。それを超えるのは一枚のスライドとは考えにくい |

## 1. 知覚ハッシュの閾値

同一分類群の全 **59,539 対**の距離を測った。

| 距離 | 対の数 |
|---|---|
| 19 | 1 |
| 34 | 1 |
| 35 | 1 |
| **36〜54** | **0(谷)** |
| 55 | 1 |
| 57 | 1 |
| 59 | 3 |
| … | 以降なだらかに増え、中央は 128 付近(乱数対と同じ) |

閾値 45 は谷の中にある。**数ずらしても結果は変わらない**(36〜54 のどこでも同じ 3 組)。

### まとめすぎの検査

閾値内で最も遠い 3 組(距離 19 / 34 / 35)を目で見た → `merged_farthest.jpg`。
`Micrococcus spp 18/24`・`Bifidobacterium spp 43/54`・`Micrococcus spp 19/25` の
いずれも**同一視野**で、まとめすぎではない。

参考として閾値を 80 まで緩めて見たところ、距離 76〜80 の対は**明らかに別視野**だった
(菌の配置が違い、背景が似ているだけ)。緩める側の限界は 55 の手前にある。

### まとめ足りない検査

閾値の外で最も近い対(距離 55 / 57 / 59)を目で見た → `apart_nearest.jpg`。
いずれも `Micrococcus spp` のほぼ空の視野で、少数の菌の位置が違う**別視野**である。
まとめ足りないのではなく、**まとめるべきでないものが近く見えている**。

### 別の尺度と食い違った

独立の尺度として 32x32 RGB サムネイルの正規化 L2 距離も測った。
両者の順位相関は **0.06** しかない。L2 の最小対は
`Bacteroides fragilis 48/49`(L2 0.927・dhash 79)のような**同じくらい淡い視野**であり、
同一視野ではなかった。**L2 は色の近さを測り、dhash は構図の近さを測っている。**
同一視野の検出には dhash を採る。

## 2. スライドの代理

同一 (分類群, キャンバス寸法) のセルを数えた。1225px を除く 421 セルのうち:

| セルの枚数 | セル数 |
|---|---|
| 1 | 40 |
| 2 | 22 |
| **3** | **264** |
| 4 | 25 |
| 5 | 10 |
| 6 | 47 |
| 7 / 9 / 10 / 11 / 12 | 2 / 8 / 1 / 1 / 1 |

**3 の倍数が 320 / 421(76%)。** 一つの視野につき 3 枚撮る運用があったように見える。

### ところが、同一寸法の 3 枚組は同一視野ではなかった

264 の 3 枚セルすべてについて、セル内の dhash 対距離を測った。

| 統計 | 値 |
|---|---|
| 中央値 | 126 |
| 最小 | 78 |
| 最大 | 155 |

**乱数対(中央 128)と変わらない。** 目視でも別の視野である(`triplets` の確認)。
染色の濃さ・背景・ピントだけが揃っている。つまりこれは**同じスライドの別視野**であり、
配布物に無い撮影セッション ID の代わりとして使える。

### 1225px は代理にならない

1225px は 22 分類群にまたがって 539 枚(全体の 27.4%)ある。
一枚のスライドから 55 視野という規模ではないので、別の書き出し経路と見られる。
セルの枚数は 21〜55 に達する。

したがって **12 枚を上限**とし、それを超えるセルはまとめない。

## 3. 結果と、残った甘さ

| 項目 | 値 |
|---|---|
| 画像 | 1,966 |
| group | 929 |
| 2 枚以上を含む group | 388(最大 12 枚) |
| スライドの代理で結合したセル | 388 |
| 知覚ハッシュで結合した対 | 3 |
| **手がかりの無い大きなセルに残った画像** | **503 枚(25.6%)** |

**画像の 4 分の 1 は group を作れないまま残っている。** 同じスライドから来ていても、
それを示す手がかりが無い。この分だけ物差し A(画像単位)は甘い方へ寄る。

**これは直せない。** 撮影セッション ID は配布物に無く、画像から復元する手段も
(1225px の中では)見つからなかった。**物差し B と C を置く理由の一つがこれである** ——
分類群ごと・科ごとに抜けば、スライドの手がかりが無くても leakage は起きない。
